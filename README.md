# FOKO AI (فوکو) 🚀

> دستیار هوشمند، خودمختار و همه‌کاره‌ی اندروید با مکالمه‌ی زنده‌ی صوتی/متنی، ویجت شناور، بینایی صفحه، مرورگرخوانی، اتصال به ابزارها و ارتقای خودکار.

**FOKO** یک اپلیکیشن اندروید (Kotlin + Jetpack Compose) است که یک عامل (agent) خودمختار را در دسترس شما می‌گذارد. فوکو می‌تواند با شما صحبت کند، صفحه را ببیند، وب را بخواند، فایل ذخیره کند، به گیت‌هاب و Hugging Face و گوگل درایو وصل شود و هر دانشی را که نمی‌داند خودش یاد بگیرد و در مخزن گیت‌هاب شما بارگذاری کند.

## ✨ قابلیت‌های اصلی

| قابلیت | توضیح |
| --- | --- |
| 🎙️ مکالمه‌ی زنده‌ی دوطرفه | صحبت کنید، فوکو می‌شنود، فکر می‌کند و صوتی پاسخ می‌دهد (SpeechRecognizer + TextToSpeech). |
| 🫧 ویجت شناور | خارج از برنامه و روی هر اپی. با رنگ گوی وضعیت را نشان می‌دهد: **سبز = شنیدن**، **قرمز = تفکر**، **آبی = پاسخ**. |
| 🙈 دکمه‌ی مخفی | نگه‌داشتن گوی، ویجت را مخفی می‌کند؛ یک ضربه دوباره ظاهر می‌شود. |
| 👁️ بینایی و مرورگرخوانی | خواندن متن صفحه‌ی جاری (Accessibility) و خواندن کامل صفحات وب. |
| 🧠 عامل خودمختار | هر درخواست را تحلیل می‌کند، ابزار لازم را انتخاب و اجرا می‌کند و ادامه می‌دهد تا کار تمام شود. |
| 🔎 جستجوی زنده‌ی وب | جستجو در DuckDuckGo و استخراج نتایج واقعی. |
| 🔗 اتصال به ابزارها | GitHub، Hugging Face و Google Drive با API واقعی. |
| 💾 ذخیره و دانلود | ذخیره‌ی متن/فایل در حافظه‌ی گوشی و بارگذاری در درایو/گیت‌هاب. |
| ⬆️ ارتقای خودکار | اگر کاری را نداند: جستجو می‌کند، می‌خواند، خلاصه می‌سازد و دانش را در `knowledge/` مخزن گیت‌هاب شما کامیت می‌کند. |
| 🗃️ حافظه‌ی بلندمدت | یادداشت‌ها و دانش‌های قبلی در گفتگوهای بعدی به کار می‌روند. |
| 🤖 هوش مصنوعی | از طریق Hugging Face (مدل‌هایی مثل Qwen 2.5، DeepSeek R1 و Llama). |

## 🧩 معماری

```
                     [ کاربر: صدا / متن ]
                              │
                              ▼
                 ┌────────────────────────┐
                 │   AgentEngine (عامل)   │
                 │  حلقه‌ی تفکر + ابزار   │
                 └───────────┬────────────┘
                             │
        ┌────────────────────┼─────────────────────┐
        ▼                    ▼                     ▼
  [ AiRouter ]        [ FokoTools ]        [ FokoMemory ]
  Hugging Face         ابزارهای واقعی        حافظه‌ی بلندمدت
                             │
     ┌──────────┬────────────┼───────────┬──────────────┐
     ▼          ▼            ▼           ▼              ▼
  وب/مرورگر  صفحه‌خوان    دستگاه      GitHub/HF      Google Drive
```

- **`app/`** — اپلیکیشن اندروید (این ماژول اصلی است).
- **`foko_orchestrator.py`** — نمونه‌ی هماهنگ‌کننده‌ی چندعاملی روی سرور.
- **`docs/`** — مستندات طراحی.

> پوشه‌های `JARVIS-1/2/3` در این مخزن قرار داده نشده‌اند: آن‌ها پروژه‌های متن‌باز جداگانه و حجیم (بیش از ۱۰۰ مگابایت) بودند و به‌صورت وابستگی بیرونی نگهداری می‌شوند. این مخزن فقط شامل کد اپلیکیشن فوکو است.

## 🚀 ساخت و نصب

### پیش‌نیازها
- JDK 17
- Android SDK (Platform 36، Build-Tools 36)

### ساخت با خط فرمان
```bash
cp .env.example .env          # کلیدهای اختیاری
./gradlew :app:assembleDebug
```
فایل APK در مسیر `app/build/outputs/apk/debug/` ساخته می‌شود.

### ساخت خودکار
هر push روی شاخه‌ی `main` به‌صورت خودکار توسط GitHub Actions ساخته می‌شود و APK به‌عنوان artifact آپلود می‌گردد (`.github/workflows/android.yml`).

## 🔑 تنظیم کلیدها و ابزارها

همه‌ی این موارد داخل خود برنامه انجام می‌شود:

- **تب «گفتگو»** → کلید Hugging Face در «تنظیمات».
- **تب «ابزارها»** → اتصال GitHub، Hugging Face و Google Drive، روشن/خاموش کردن ویجت شناور و ارتقای خودکار.

### مجوزها
- **میکروفون** — مکالمه‌ی صوتی.
- **نمایش روی برنامه‌های دیگر** — ویجت شناور.
- **دسترسی‌پذیری (Accessibility)** — بینایی صفحه و کنترل دستگاه.
- **اعلان‌ها** — اعلان دائمی سرویس شناور.

# Knowledge Base (پایگاه دانش فوکو)

این پوشه محل بارگذاری خودکار دانشی است که FOKO AI هنگام نداشتن اطلاعات، از وب یاد می‌گیرد.

- هر موضوع در یک فایل Markdown جداگانه با نام `<slug>.md` ذخیره می‌شود.
- فایل‌ها به‌صورت خودکار توسط ابزار `harvest_knowledge` ساخته و کامیت می‌شوند.
- برای فعال بودن این قابلیت، توکن گیت‌هاب را در تب «ابزارها» وارد کنید و گزینه‌ی «ارتقای خودکار» را روشن نگه دارید.

این فایل به‌عنوان نقطه‌ی شروع و راهنمای پوشه در نظر گرفته شده است.

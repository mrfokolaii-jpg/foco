# جستجوی حرفه‌ای در وب

## عملگرهای گوگل که واقعاً کار می‌کنند
```
"عبارت دقیق"            جستجوی عین جمله
site:دامنه              فقط داخل یک سایت
filetype:pdf            فقط فایل PDF (یا xlsx، pptx)
-کلمه                   حذف کلمه از نتایج
OR                      یکی از دو گزینه
intitle:کلمه            کلمه در عنوان صفحه
related:دامنه           سایت‌های مشابه
before:2024 after:2023  محدودهٔ زمانی
*                       هر چیزی جای این ستاره
```
مثال ترکیبی: `site:github.com "compose" kotlin filetype:md after:2024`

## جستجوی GitHub (طلا برای برنامه‌نویس‌ها)
```
language:kotlin          فقط کوتیلین
stars:>500               محبوب‌تر از ۵۰۰ ستاره
path:src/main            محدود به مسیر
filename:build.gradle    نام فایل
org:گوگل                 داخل سازمان مشخص
fork:false               بدون پروژه‌های کپی‌شده
```
ترتیب: پروژه‌ای پیدا کن که مشکل مشابه تو را حل کرده، بعد کدش را بخوان.

## جستجوی خطای برنامه‌نویسی (مؤثرترین روش)
1. متن خطا را **کامل و داخل گیومه** بگذار.
2. نام کتابخانه و نسخه را اضافه کن.
3. زبان را اضافه کن.
4. اگر جواب نبود، کل خطا را حذف کن و فقط پیام اصلی را بگذار.
5. جواب‌های قدیمی را با نسخهٔ خودت مقایسه کن؛ ممکن است منقضی شده باشند.

## منابع اولیه در برابر ثانویه
- **اولیه**: مستندات رسمی، مخزن کد، مقالهٔ خود سازنده. قابل اعتمادترین.
- **ثانویه**: آموزش‌ها، ویدیوها، پست‌های وبلاگی. مفید برای شروع.
- **بی‌اعتبار**: سایت‌های کپی‌کننده، محتوای تاریخ‌گذشته، پاسخ‌های بدون منبع.

قاعده: عدد و نسخه و قانون را فقط از منبع اولیه بگیر.

## ارزیابی اعتبار یک صفحه
- چه کسی نوشته؟ تاریخش کِی است؟
- منبعش را معرفی کرده؟
- تبلیغ یا فروش چیزی در آن هست؟
- با دو منبع مستقل دیگر هم‌خوان است؟

## جستجوی تصویر
- برای پیدا کردن منبع عکس: جستجوی تصویر معکوس.
- برای پیدا کردن متن داخل عکس: قابلیت استخراج متن (OCR) ابزارهای ترجمه/اسکن.
- برای عکس با کیفیت: کلمهٔ `high resolution` یا `4k` + `site:` منبع معتبر.

## پرسیدن سؤال درست (مهندسی پرامپت جستجو)
بد: «سئو»
خوب: «چک‌لیست سئوی تکنیکال برای فروشگاه اینترنتی فارسی ۲۰۲۵»

بد: «کد کار نمی‌کند»
خوب: «Kotlin Compose: خطای Unresolved reference: rememberScrollState در نسخهٔ ۱.۳»

## گردآوری و ذخیرهٔ نتیجه
- هر منبع را با تاریخ و آدرس کنار یادداشتت بنویس.
- نکته‌های مهم را کپی نکن؛ با جملهٔ خودت بنویس (فهم بهتر، حق تکثیر رعایت‌شده).
- بعد از هر پژوهش، خلاصهٔ یک‌صفحه‌ای برای خودت بساز.

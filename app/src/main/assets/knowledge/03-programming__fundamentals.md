## ساختار داده و سرعت (به زبان ساده)
| ساختار | کاربرد | سرعت دسترسی |
|---|---|---|
| لیست | ترتیب مهم است | کند در جستجو |
| دیکشنری/هش | جستجوی سریع با کلید | خیلی سریع |
| مجموعه | حذف تکراری‌ها | خیلی سریع |

قاعدهٔ عملی: اگر داخل حلقه دنبال چیزی می‌گردی، به‌جای لیست از دیکشنری استفاده کن.

## مفاهیم پایه که هیچ‌وقت عوض نمی‌شوند
- متغیر، شرط، حلقه، تابع
- ساختمان داده و انتخاب درست آن
- پیچیدگی زمانی (تقریبی: چند بار روی داده حرکت می‌کنی)
- مدیریت خطا (امتحان کن، نگرفتن خطا را نادیده نگیر)
- خوانایی کد مهم‌تر از زیرکی کد است

## شیءگرایی در برابر تابعی
- شیءگرا: چیزها را با ویژگی و رفتارشان مدل کن. مناسب سیستم‌های بزرگ و مدل‌سازی واقعیت.
- تابعی: کار با توابع خالص و بدون تغییر داده. مناسب پردازش داده و همزمانی.
- در عمل هر دو را با هم استفاده می‌کنی.

## تست
- تست واحد: کوچک‌ترین تابع را جدا امتحان می‌کند. سریع و ارزان.
- تست یکپارچگی: چند بخش با هم.
- تست دستی/کاربری: قبل از انتشار.
قاعده: برای هر اشکالی که پیدا می‌کنی، یک تست بنویس که دیگر تکرار نشود.

## دیباگ سیستماتیک (۵ گام)
1. خطا را **بازتولید** کن. بدون بازتولید، حدس زدن بی‌فایده است.
2. متن کامل خطا را بخوان — معمولاً جواب داخل خودش است.
3. حدس بزن کدام خط مشکل دارد، بعد با چاپ مقادیر آن را **اثبات** کن.
4. یک چیز را در هر زمان عوض کن.
5. بعد از رفع، علت ریشه‌ای را بفهم؛ وگرنه دوباره برمی‌گردد.

## Git: کارهای روزمره
```
git status                 وضعیت فعلی
git add -A                 افزودن همهٔ تغییرات
git commit -m "پیام"       ثبت
git push                   فرستادن به سرور
git pull --rebase          گرفتن تغییرات جدید
git checkout -b نام        شاخهٔ تازه
git merge نام              ادغام شاخه
git log --oneline -10      تاریخچهٔ کوتاه
git diff                   تغییرات ثبت‌نشده
git restore فایل           برگرداندن یک فایل
git stash / git stash pop  کنار گذاشتن موقت تغییرات
```
حل تعارض: فایل را باز کن، بین نشانه‌ها یکی را انتخاب کن، نشانه‌ها را پاک کن،
`git add` و بعد `git commit`.

## SQL پایه
```
SELECT نام FROM جدول WHERE شرط ORDER BY ستون DESC LIMIT 10;
INSERT INTO جدول (ستون) VALUES (مقدار);
UPDATE جدول SET ستون = مقدار WHERE شرط;
DELETE FROM جدول WHERE شرط;
JOIN  -- وصل کردن دو جدول از روی یک کلید مشترک
INDEX -- سرعت‌دهندهٔ جستجو
```

## اشتباه‌های رایج تازه‌کارها
- کپی کد بدون فهمیدن
- نام‌گذاری مبهم (`a`, `x1`, `data2`)
- تکرار کد به‌جای ساختن تابع
- نادیده گرفتن خطاها
- عجله در انتخاب فریم‌ورک پیش از یادگیری مبانی

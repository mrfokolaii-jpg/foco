# امنیت دیجیتال — چک‌لیست شخصی

## حساب‌ها
- [ ] برای ایمیل اصلی، رمز یکتا و طولانی
- [ ] ورود دو مرحله‌ای (2FA) با برنامهٔ رمزساز، نه پیامک
- [ ] مدیر رمز عبور برای بقیهٔ حساب‌ها
- [ ] کدهای پشتیبان 2FA را جدا و آفلاین نگه دار
- [ ] هر چند ماه، دستگاه‌های وارد‌شده را بررسی کن و ناشناس‌ها را بیرون کن

## فیشینگ و مهندسی اجتماعی
نشانه‌ها: عجله، تهدید، لینک کوتاه‌شده، دامنهٔ شبیه‌سازی‌شده (حرف اضافه یا جابه‌جا)،
درخواست رمز یا کد یک‌بارمصرف، پیام از «مدیر» یا «پشتیبانی».

قاعدهٔ طلایی: هر کسی کد یک‌بارمصرف یا عبارت بازیابی خواست، کلاهبردار است.

## امنیت کلید API در اپ‌ها
- کلید را داخل اپ موبایل جاسازی نکن؛ با ابزارهای ساده از فایل APK خوانده می‌شود.
- کلید را از کاربر بگیر و در حافظهٔ خود دستگاه نگه دار.
- در سمت سرور، دسترسی کلید را محدود کن (فقط همان کاری که لازم است).
- کلیدها را دوره‌ای عوض کن و قدیمی‌ها را باطل کن.

## موبایل
- فقط از منابع رسمی اپ نصب کن.
- اجازه‌ها را بررسی کن: یک اپ چراغ‌قوه به مخاطبین دسترسی ندارد.
- امضای اپ: هر انتشار باید با همان کلید امضا شود.
- قفل صفحه با رمز عددی حداقل ۶ رقمی، اثر انگشت/چهره.
- رمزنگاری حافظه را فعال کن.

## رمزنگاری: چند مفهوم
- **هش** (مثل SHA-256): یک‌طرفه؛ برای ذخیرهٔ رمز. برگرداندنی نیست.
- **رمزنگاری متقارن**: یک کلید برای رمز و گشودن؛ سریع.
- **رمزنگاری نامتقارن**: کلید عمومی برای رمز، کلید خصوصی برای گشودن.
- **نمک (salt)**: مقدار تصادفی که هش رمز را یکتا می‌کند.
هیچ‌وقت رمز کاربر را بدون هش ذخیره نکن.

## پشتیبان‌گیری
- قانون ۳-۲-۱: سه نسخه، دو رسانه، یک نسخه خارج از محل.
- یک بار بازیابی را تمرین کن؛ پشتیبانی که بازیابی نشود، پشتیبان نیست.
- پشتیبان را هم رمزنگاری کن.

## حریم خصوصی
- کمترین دادهٔ لازم را جمع کن.
- داده‌ای که نگه نمی‌داری، لو نمی‌رود.
- پیام‌های گروهی و اسکرین‌شات‌ها را قبل از فرستادن بررسی کن.

# راهنمای استفاده از پایگاه دانش فوکو

## این فایل‌ها چیست
مجموعه‌ای از یادداشت‌های کاربردی دربارهٔ کارهایی که واقعاً به آن‌ها نیاز داری:
طراحی سایت، ساخت اپلیکیشن، برنامه‌نویسی، سئو، شبکه‌های اجتماعی، ترید و ارز دیجیتال،
هوش مصنوعی، ابزارها، امنیت و جستجوی حرفه‌ای.

## چطور استفاده شود
۱. فایل ZIP را در اپ فوکو از بخش «پایگاه دانش» وارد کن.
۲. اپ همهٔ فایل‌ها را می‌خواند و به قطعه‌های کوچک می‌شکند.
۳. وقتی سؤالی می‌پرسی، اپ فقط قطعه‌های مربوط به همان سؤال را پیدا می‌کند و به مدل
   آفلاین می‌دهد. به این روش «RAG» می‌گویند.
۴. برای امتحان، در همان صفحهٔ تنظیمات یک کلمه مثل «سئو» یا «ترید» را جستجو کن؛
   همان چیزهایی که پیدا می‌شود، به مدل داده خواهد شد.

## چرا این‌طور بهتر است
مدل کوچک روی گوشی به‌تنهایی دانش تخصصی ندارد. جای بزرگ کردن مدل (که کند و داغ
می‌کند)، دانش را کنارش می‌گذاریم و هر بار فقط بخش مربوطه را جلوی چشمش می‌گیریم.

## نکته‌ها
- همه‌چیز روی خود گوشی است: نه اینترنت، نه حساب، نه کلید.
- اگر جواب مدل ناقص بود، سؤال را کوتاه‌تر و دقیق‌تر بپرس.
- برای موضوعات حقوقی، مالی و پزشکی، این یادداشت‌ها جای مشاور متخصص را نمی‌گیرند.
